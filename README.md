# CrimLib — тегін электрондық анықтамалық

## Жергілікті іске қосу
1. `crimlib` бумасын ашыңыз.
2. `index.html` файлын браузерде ашып көріңіз. Кейбір браузерлер `fetch()` арқылы JSON файлдарын `file://` режимінде оқуға рұқсат бермейді.
3. Сондықтан ең оңай тексеру: VS Code ішіндегі Live Server кеңейтімін пайдалану немесе GitHub Pages-ке жариялау.

## GitHub Pages арқылы жариялау
1. GitHub аккаунтына кіріңіз: https://github.com/
2. `New repository` басыңыз.
3. Репозиторий атауын `crimlib` деп қойыңыз, `Public` таңдаңыз, `Create repository` басыңыз.
4. Осы жобадағы барлық файлдар мен бумаларды репозиторийдің түбіріне жүктеңіз (`index.html` түбірде тұруы керек).
5. Репозиторийде `Settings` → `Pages` бөліміне өтіңіз.
6. `Build and deployment` астынан `Deploy from a branch` таңдаңыз.
7. Branch: `main`, folder: `/ (root)` таңдаңыз да `Save` басыңыз.
8. Біраз уақыттан кейін сайт `https://GITHUB-USERNAME.github.io/crimlib/` мекенжайында ашылады. `GITHUB-USERNAME` орнына GitHub логиніңізді қойыңыз.

## Telegram Mini App ретінде ашу
1. Telegram-да `@BotFather` ашыңыз.
2. `/newbot` командасымен бот жасаңыз және токенді құпия сақтаңыз.
3. `@BotFather` ішіндегі `/newapp` командасын қолданып, ботқа Mini App қосыңыз (немесе Bot Settings / Configure Mini App мәзірін пайдаланыңыз).
4. Web App URL ретінде GitHub Pages-тің HTTPS сілтемесін енгізіңіз: `https://GITHUB-USERNAME.github.io/crimlib/`.
5. Mini App-ты іске қосу батырмасын бот мәзіріне/профиліне орналастырыңыз. BotFather интерфейсіндегі нұсқауларды орындаңыз.

Ескерту: Telegram Mini App үшін HTTPS қажет. GitHub Pages HTTPS ұсынады. Ботты баптау үшін Telegram аккаунты керек, бірақ CrimLib сайтының пайдаланушыларына жеке аккаунт қажет емес.

## Материал қосу
Барлық материалдар `data/materials.json` файлында сақталады. Мысал:

```json
{
  "id": "new-topic",
  "categoryId": "inspection",
  "title": "Жаңа тақырып",
  "summary": "Қысқаша сипаттама",
  "content": "## Тақырыпша\\nМәтін.\\n\\n- Бірінші тармақ\\n- Екінші тармақ"
}
```

Мұны массивтің ішіне үтірмен бөліп қосыңыз. `id` бірегей болсын. `categoryId` мәні `data/categories.json` ішіндегі категория `id`-імен дәл сәйкес келуі керек. JSON синтаксисін бұзбаңыз.

### Қолданылатын мәтін пішімі
- `## Тақырыпша` — бөлім тақырыбы
- `- тармақ` — маркерленген тізім
- `1. тармақ` — нөмірленген тізім
- `**маңызды**` — қалың мәтін

Материалды өзгерткеннен кейін GitHub репозиторийіндегі JSON файлын жаңартыңыз. GitHub Pages өзгерісті автоматты түрде жариялайды.

## Құрылым
- `index.html` — бет құрылымы
- `style.css` — дизайн және мобильді бейімдеу
- `app.js` — навигация, іздеу, материалдарды көрсету
- `data/categories.json` — бөлімдер
- `data/materials.json` — материалдар
- `assets/favicon.svg` — сайт белгішесі

## Шектеулер
- Бұл алғашқы нұсқада іздеу материал атауы мен қысқаша сипаттамасы бойынша орындалады.
- Материал қосу GitHub-та JSON файлын өзгерту арқылы жасалады; жеке админ-панель жоқ.
- Деректер статикалық JSON файлдарында сақталады, сондықтан пайдаланушыларға аккаунт немесе серверлік база қажет емес.
- Үлгі материалдар оқу мақсатында берілген. Құқықтық нормаларды нақты қолданар алдында ресми дереккөздерден қолданыстағы редакциясын тексеріңіз.
